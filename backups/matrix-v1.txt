  /* - Hacker: terminal-green-on-black. Font is Terminal Vision (1001fonts, HipFonts) -
     same "free for personal use, not free for commercial use" situation as Bohemian
     Typewriter; flagged, Mr Eric said proceed regardless, same call as last time.

     Same structural conflict as Uzbekistan2/Grand Bazaar/Soviet (--coral/--teal/--gold/
     --coral-dark each used both as light-needing text and dark-needing tile fills
     elsewhere in the codebase, because --card is dark here too) - same ~30 call-site
     audit, same resolution.

     Two of the four tile colours are bright enough that phosphor-green text on them
     fails badly (neon green tile: 1.59:1, real fail) and need black text instead - which
     doubles as an authentic terminal touch: those two read like an active/selected
     terminal line (inverted colours), the other two read like dim background panels

     focused vs. unfocused text. */
