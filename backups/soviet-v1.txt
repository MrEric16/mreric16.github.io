  /* - Soviet Poster, given an actual signature instead of just a colour swap. Six real
     visual devices pulled from the genre (including the Gagarin/Rodina-Mat posters Mr
     Eric supplied earlier), each a genuine recurring feature of real Soviet propaganda
     print, not decoration invented for its own sake:

     1. Radiating sunburst rays behind the header title (conic-gradient) - literally in
        the Gagarin poster reference, the single most recognisable device of the genre.
     2. A bold diagonal constructivist wedge in one page corner - the Rodchenko-style
        diagonal red bar cutting across a composition.
     3. Aged-paper texture on the whole page: a vignette darkening the edges plus a real
        grain texture (SVG feTurbulence noise, not a gradient approximation) instead of
        a flat modern colour.
     4. Thick black keyline borders on every tile - propaganda posters are heavily
        woodblock/linocut in style, bold black outlines throughout.
     5. A small red star badge in the header corner - the recurring Soviet symbol,
        independent of hammer-and-sickle.
     6. A halftone dot texture layered into every tile's fill - mimics cheap mass-print
        reproduction rather than a flat vector swatch.

     All static, no animation, per the standing lesson against animating decorative
     layers. None of this touches colour or text-colour pairings - every contrast
     relationship from the previous audit is untouched, only what's drawn underneath the
     same colours changed, so nothing here needed re-auditing. */

  /* Thinning the font: Propaganda ships as a single static weight, so font-weight
     alone has nowhere lower to go - font-weight:normal (above) already rules out the
     browser synthesizing a fake bold on top, but the face's own inherent stroke
     thickness is fixed at the file level and can't be changed via font-weight at all.
     The actual way to visually thin a fixed-weight font is a text-stroke painted in
     the SAME colour as whatever's behind the text - it shaves a thin sliver off each
     glyph's outer edge, reducing how much ink-area the eye registers, without
     touching the font file itself. Applied per background context since Soviet uses
     several: beige page/card (majority of text) and the red header specifically. */
