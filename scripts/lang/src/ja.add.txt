## Can, must, want
> Can: verb stem + emasu, or koto ga dekimasu. Must: -nakereba narimasen. Want to: -tai desu. Must not: -te wa ikemasen.
row: I can | dekimasu | | できます
row: I must | -nakereba narimasen | | なければなりません
row: I want to | -tai desu | | たいです
ex: I can swim | oyogemasu | | 泳げます
ex: I cannot swim | oyogemasen | | 泳げません
ex: can you help me? | tetsudatte moraemasu ka | | 手伝ってもらえますか
ex: we must go | ikanakereba narimasen | | 行かなければなりません
ex: we must not go | itte wa ikemasen | | 行ってはいけません
ex: I want to eat | tabetai desu | | 食べたいです
ex: I do not want to eat | tabetaku arimasen | | 食べたくありません
ex: you can come | kuru koto ga dekimasu | | 来ることができます
ex: you cannot come | kuru koto ga dekimasen | | 来ることができません
ex: she wants to study | kanojo wa benkyou shitai desu | | 彼女は勉強したいです
ex: I must work today | kyou hatarakanakereba narimasen | | 今日働かなければなりません
ex: you must not run | hashitte wa ikemasen | | 走ってはいけません
## In, on, at
> Ni = at or in (where something is). De = where you do something. Japanese puts the place word after the noun: "table no ue" = on the table.
row: on | no ue | | の上
row: under | no shita | | の下
row: next to | no tonari | | の隣
row: in | no naka | | の中
ex: the book is on the table | hon wa tsukue no ue ni arimasu | | 本は机の上にあります
ex: the cat is under the table | neko wa tsukue no shita ni imasu | | 猫は机の下にいます
ex: I am at school | gakkou ni imasu | | 学校にいます
ex: I am at home | ie ni imasu | | 家にいます
ex: the shop is next to the bank | mise wa ginkou no tonari ni arimasu | | 店は銀行の隣にあります
ex: the park is near the station | kouen wa eki no chikaku ni arimasu | | 公園は駅の近くにあります
ex: we meet in the morning | asa ni aimasu | | 朝に会います
ex: the lesson is at nine | jugyou wa ku-ji desu | | 授業は九時です
ex: the key is in the bag | kagi wa kaban no naka ni arimasu | | 鍵はかばんの中にあります
## Comparing things
> "A wa B yori ..." means A is more ... than B. Use "ichiban" for "the most". Adjectives do not change for comparison.
row: more than | yori | | より
row: more | motto | | もっと
row: the most | ichiban | | 一番
ex: big, bigger, the biggest | ookii, motto ookii, ichiban ookii | | 大きい、もっと大きい、一番大きい
ex: small, smaller, the smallest | chiisai, motto chiisai, ichiban chiisai | | 小さい、もっと小さい、一番小さい
ex: this is better than that | kore wa are yori ii desu | | これはあれよりいいです
ex: this is worse than that | kore wa are yori warui desu | | これはあれより悪いです
ex: she is taller than me | kanojo wa watashi yori se ga takai desu | | 彼女は私より背が高いです
ex: Tashkent is bigger than Samarkand | tashukento wa samarukando yori ookii desu | | タシケントはサマルカンドより大きいです
ex: it is the cheapest | ichiban yasui desu | | 一番安いです
ex: the same as | to onaji | | と同じ
